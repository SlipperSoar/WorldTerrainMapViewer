# 功能介绍

## 行星地形图查看

### 导入

工具支持将自己的地形图通过`streamingAssets`目录导入，并可点击将其应用在“地球”上

如果有与地形图**配套的高度图**，同样可以导入，只需要按照规则命名即可自动生效。星球表面会根据地形图的高度图信息自动形成高低起伏的地形。

**高度图不会被列入可选的地形图列表**。

目录结构示例：
- streamingAssets/
  - my_world_terrain_map.png
  - my_world_terrain_map_height.png

### 查看

工具支持以下功能：

- 昼夜切换
- 季节切换
- 右键拖拽旋转视角
- 一键切换至特定视角
- 一键切换至特定季节
- 点击在星球表面打上标记
- 按键盘的字母区顶部的0-9数字按键，切换打标记使用的颜色
- 点击屏幕底部快捷键上方的标记预览列表中的特定标记，删除对应标记

## 行星地形图生成

### 生成逻辑

本工具采用以下方式生成地形图

1. 提供一个随机种子，以种子为基础进行随机。（如果没有则使用本机时间作为种子）
2. 先在\[-10000m, 10000m\]范围内进行高度的随机生成
3. 随机划分若干板块，进行几次板块运动，计算板块运动造成的影响
4. 依据气候场计算**水系**（河网、湖泊、三角洲、季节性河流，见下）
5. 依据**地轴倾角**（地图属性，见下）推算永久雪线与冰盖范围：
   - 低纬度地区只有较高的山峰才有常年积雪
   - 纬度越高雪线越低，高纬度地区接近海平面即常年积雪
   - 极区形成连片冰盖，极地海面形成海冰
6. 将高度图的灰度图保存至`streamingAssets`目录下
7. 根据高度信息、水系信息与冰盖信息，生成对应的彩色地形图
8. 将生成好的地形图保存至`streamingAssets`目录下

### 气候场

湿度由**纬度（大气环流）+ 距海距离（大陆性）+ 噪声**共同决定，水文与地形分类共用同一套结果：

- 赤道辐合带湿润、副热带干旱带干燥、西风带湿润、极地干燥
- 距海越远越干燥（大陆性），因此内陆会出现沙漠与草原
- 湿润度同时用于判定期季节性河流、沙漠沿途渗漏与雪线的干湿区间

### 水文（河网、湖泊、三角洲）

水系不是逐条「从山头往下画」，而是先建立全域的汇流关系，再由流量决定河宽：

1. **填洼与流向**：以海洋为起点做 Priority-Flood，把内陆洼地填平，同时确定每一格的唯一流向。
   这样任何一格都必然有一条单调下降的路径入海，河流不会倒流或凭空断掉。
   排序键上加了一个很小的相干扰动，用来打散平地上的网格状直河道，使水系自然蜿蜒
2. **汇流累积**：按水面高程从高到低把水从上游累加到下游。本地产流与地形高度相关（高山降雨/融雪更多），
   并按湿度缩放（干旱区产流很少）
3. **河宽由流量决定**：`河宽 = 0.7 + 1.25·((Q/Q₀)^0.52 - 1)` 像素（上限 12 像素）
   - 多条支流汇合 → 流量跃升 → **河面变宽**
   - 主干在平缓段分流 → 流量被分走 → 两支都**收窄**
   - 干流还会按宽度加粗掩膜，使它在图上真正比支流宽出好几个像素
4. **分流（辫状/分汊）**：在水面坡降很小的冲积平原段，允许河道把一部分流量分给第二个去向，
   形成「主干分出支流」的分汊河段
5. **湖泊**：填洼时被抬高的**闭合洼地**才算湖泊。填平只用于确定流向（保证每格都能入海），
   并不会修改地形高程；达不到「显著」门槛的小洼地只当作普通地形，水从上面流过去而已。
   门槛为：连通面积 ≥ 全图格数的 0.019%（随分辨率缩放，下限 24 格）、盆地最大水深 ≥ 8 m，
   盆地边缘水深不足 2 m 的浅滩仍按陆地处理
6. **三角洲**：河道入海处，若前方是浅海（水深小于 900 m），会分出 2–5 条分流河道呈扇形铺开，
   河越宽三角洲越大；水太深则冲刷不出三角洲
7. **季节性河流**：集水区平均湿度低于半干旱上限、且属于本地河网中最干的那四分之一时，
   河道标记为季节性（间歇性）河流，在图上以更淡的沙蓝色绘制 —— 湿润世界几乎没有，干旱世界大量出现
8. **干旱区沿途渗漏**：河道经过干旱区时流量按比例衰减，因此沙漠中的河流可能中途消失或越走越细

### 人文（聚落、国家、交通、中文地名）

生成链路：`自然地理 → 宜居度 → 人口势场 → 聚落 → 国家 → 人口 → 中文命名 → 交通网络`

1. **宜居度**：由最热月气温适宜度、湿度、靠近河湖、靠海、地形起伏共同决定，并扣除洪涝与严寒
2. **人口势场** = 宜居度 × 多尺度噪声（所以人口不是随机撒点）
3. **聚落**：按势场加权的泊松盘采样 —— 势场越高越密，等级越高间距越大；等级分 都 / 城 / 镇 / 村
4. **国家**：人口最大的若干聚落作首都，用**成本距离**竞争出势力范围（山脉与海洋昂贵、河谷便宜），
   于是国界会自然沿山脉、河流与海岸展开
5. **人口**：先算每个聚落的腹地人口（多源成本距离划分腹地），再套 **Zipf 律**：
   第 r 大城市人口 ≈ 最大城市人口 / r^0.9
6. **中文命名**：`地理特征 → 命名风格包 → 词库 → 模板组合 → 过滤去重`。
   风格包按气候/地形选取（北境寒地 / 中原农耕 / 海岛贸易 / 沙漠游牧 / 南方水乡 / 山地矿镇），
   后缀按等级与功能匹配（港/津/埠、关/隘、矿/盐、京/都…），
   并做长度、专名重复、同音、连续同字、语义冲突过滤 —— 沙漠里不会出现「某某港」，雪原不会出现热带词
7. **交通网络**：引力模型（人口积 ÷ 距离^γ）排序 → 最小生成树保证连通 → 追加高强度边 →
   在成本场（坡度、海洋、河谷）上寻路，得到陆路 / 河运 / 海运三种交通线
8. **保存与叠加显示**：
   - 完整数据保存为 `<地图名>_human.json`（聚落、国家、交通线、自然地名、势力范围栅格）
   - 摘要写进地图属性 `<地图名>_meta.json` 的 `human` 字段（数量与总人口）
   - 载入地图时叠加显示在地球表面：**势力范围染色 + 国界 + 交通线 + 聚落点 + 城镇中文地名标签**，
     顶栏的「人文」开关可以整体显隐
   - 地名标签只显示**朝向相机的那一面**：镜头转到另一侧时自动消失，转回来再出现；
     靠近地平线时按球面可见性（`n·相机方向 > R/D`）渐隐，避免生硬地跳出

### 地图属性（地轴倾角）
**地轴倾角**（黄赤交角，0°-90°）是一张地形图自身携带的属性，在生成时通过界面上的滑动条设定：

- 影响光照：倾角越大，极地的季节差异越剧烈；倾角为 0° 时没有季节变化
- 影响冰盖：倾角越大，高纬夏季越暖、雪线越高，冰盖越向极地退缩；倾角越小，雪线越低、冰盖越向低纬扩展
- 雪线（终年积雪下限）由纬度与倾角的半经验公式给出（λ=|纬度|、ε=地轴倾角，单位 km）：

  ```
  海平面最热月平均气温  T_s = 28 - 0.0055·λ² + 1.0·(ε-23.44)·(λ/90)²      [℃]
  雪线中值              H_m = max(T_s, 0) / 5.5                            [km]
  雪线区间              H_min = max(0, H_m-(0.7+0.012λ))                   湿润（海洋性）
                        H_max = H_m+(1.0+0.022λ)                          干旱（内陆）
  ```

  生成时用地图自身的湿度场在区间内插值：湿润山地取低雪线、干旱内陆取高雪线，因此积雪分布会随气候带自然起伏
- 冰盖与海冰界限同样由该公式推得：最热月平均气温 ≤ 0℃ 的纬度即海平面终年积雪（陆地冰盖）界限，更冷约 2℃ 处为海冰界限
- 公式给出的是真实海拔（赤道约 5.1 km），而生成地图的起伏通常只有 1~2 km，因此雪线按「地图最高陆地海拔 ÷ 地球陆地最高海拔 8848 m」等比标定后使用，这样公式里的纬度、倾角与干湿差异都能在同一比例下体现

生成时会在地形图旁写入元数据文件 `<地图名>_meta.json`（记录地轴倾角、水面占比、种子等）。载入该地图时，工具会自动读取并应用其中的地轴倾角；没有元数据文件的地图按默认值 23.5° 处理。

> 侧边栏中的地轴倾角滑动条是**下一次生成**的参数，拖动它不会改变当前星球显示的倾角。
> 星球始终坚持显示当前所选中地图生成时使用的倾角，只有在「生成完成」或「切换到另一张地图」时才会改变。
> 如果生成过程中又拖动了滑动条，生成结束后滑动条会自动回到本次实际使用的数值。

### 使用方式

#### 自己生成

1. 鼠标移动到画面左侧，引出侧边栏
2. （可选）填写用于生成的随机种子
3. 调整星球的水面占比
4. 拖动**地轴倾角**滑动条设置本次生成要使用的地轴倾角（0°-90°）
5. 点击生成，等待进度100%（完成）后自动应用至星球预览，此时星球的倾角即为该地图的倾角

#### 查看他人分享的地形

**本地文件方式**

1. 将他人分享的地形图添加进`streamingAssets`目录下
2. （可选）将他人分享的对应高度图也添加进`streamingAssets`目录下
3. （可选）将他人分享的对应元数据文件 `<地图名>_meta.json` 也添加进`streamingAssets`目录下，即可自动还原该地图的地轴倾角
4. 运行工具，鼠标移动到画面左侧，引出侧边栏
5. 在侧边栏下方列表中，点击选中刚刚添加的地形图即可

**自行生成方式**

1. 得到他人生成地形图时使用的**随机种子**（如生成时没有填写，则生成后会将使用的随机种子显示在种子的输入栏）
2. 得到他人生成地形图时使用的**水面占比**
3. 得到他人生成地形图时使用的**地轴倾角**
4. 运行工具，鼠标移动到画面左侧，引出侧边栏
5. 将得到的随机种子填写进侧边栏顶部的种子输入框中
6. 将水面占比拖动至与他人相同的值
7. 将地轴倾角拖动至与他人相同的值
8. 点击生成按钮后等待结果即可
