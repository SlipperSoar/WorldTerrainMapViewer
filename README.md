# 功能介绍

## 行星地形图查看

### 导入

工具支持将自己的地形图通过`streamingAssets`目录导入，并可点击将其应用在“地球”上

如果有与地形图**配套的高度图**，同样可以导入，只需要按照规则命名即可自动生效。星球表面会根据地形图的高度图信息自动形成高低起伏的地形。

**高度图不会被列入可选的地形图列表**。

目录结构示例：
- streamingAssets/
  - my_world_terrain_map.png
  - my_world_terrain_map_height.png

### 查看

工具支持以下功能：

- 昼夜切换
- 季节切换
- 右键拖拽旋转视角
- 一键切换至特定视角
- 一键切换至特定季节
- 点击在星球表面打上标记
- 按键盘的字母区顶部的0-9数字按键，切换打标记使用的颜色
- 点击屏幕底部快捷键上方的标记预览列表中的特定标记，删除对应标记

## 行星地形图生成

### 生成逻辑

本工具采用以下方式生成地形图

1. 提供一个随机种子，以种子为基础进行随机。（如果没有则使用本机时间作为种子）
2. 先在\[-10000m, 10000m\]范围内进行高度的随机生成
3. 随机划分若干板块，进行几次板块运动，计算板块运动造成的影响
4. 计算河流、湖泊的发源
5. 依据**地轴倾角**（地图属性，见下）推算永久雪线与冰盖范围：
   - 低纬度地区只有较高的山峰才有常年积雪
   - 纬度越高雪线越低，高纬度地区接近海平面即常年积雪
   - 极区形成连片冰盖，极地海面形成海冰
6. 将高度图的灰度图保存至`streamingAssets`目录下
7. 根据高度信息、河流湖泊信息与冰盖信息，生成对应的彩色地形图
8. 将生成好的地形图保存至`streamingAssets`目录下

### 地图属性（地轴倾角）

**地轴倾角**（黄赤交角，0°-90°）是一张地形图自身携带的属性，在生成时通过界面上的滑动条设定：

- 影响光照：倾角越大，极地的季节差异越剧烈；倾角为 0° 时没有季节变化
- 影响冰盖：倾角越大，高纬夏季越暖、雪线越高，冰盖越向极地退缩；倾角越小，雪线越低、冰盖越向低纬扩展
- 雪线（终年积雪下限）由纬度与倾角的半经验公式给出（λ=|纬度|、ε=地轴倾角，单位 km）：

  ```
  海平面最热月平均气温  T_s = 28 - 0.0055·λ² + 1.0·(ε-23.44)·(λ/90)²      [℃]
  雪线中值              H_m = max(T_s, 0) / 5.5                            [km]
  雪线区间              H_min = max(0, H_m-(0.7+0.012λ))                   湿润（海洋性）
                        H_max = H_m+(1.0+0.022λ)                          干旱（内陆）
  ```

  生成时用地图自身的湿度场在区间内插值：湿润山地取低雪线、干旱内陆取高雪线，因此积雪分布会随气候带自然起伏
- 冰盖与海冰界限同样由该公式推得：最热月平均气温 ≤ 0℃ 的纬度即海平面终年积雪（陆地冰盖）界限，更冷约 2℃ 处为海冰界限
- 公式给出的是真实海拔（赤道约 5.1 km），而生成地图的起伏通常只有 1~2 km，因此雪线按「地图最高陆地海拔 ÷ 地球陆地最高海拔 8848 m」等比标定后使用，这样公式里的纬度、倾角与干湿差异都能在同一比例下体现

生成时会在地形图旁写入元数据文件 `<地图名>_meta.json`（记录地轴倾角、水面占比、种子等）。载入该地图时，工具会自动读取并应用其中的地轴倾角；没有元数据文件的地图按默认值 23.5° 处理。

> 侧边栏中的地轴倾角滑动条是**下一次生成**的参数，拖动它不会改变当前星球显示的倾角。
> 星球始终坚持显示当前所选中地图生成时使用的倾角，只有在「生成完成」或「切换到另一张地图」时才会改变。
> 如果生成过程中又拖动了滑动条，生成结束后滑动条会自动回到本次实际使用的数值。

### 使用方式

#### 自己生成

1. 鼠标移动到画面左侧，引出侧边栏
2. （可选）填写用于生成的随机种子
3. 调整星球的水面占比
4. 拖动**地轴倾角**滑动条设置本次生成要使用的地轴倾角（0°-90°）
5. 点击生成，等待进度100%（完成）后自动应用至星球预览，此时星球的倾角即为该地图的倾角

#### 查看他人分享的地形

**本地文件方式**

1. 将他人分享的地形图添加进`streamingAssets`目录下
2. （可选）将他人分享的对应高度图也添加进`streamingAssets`目录下
3. （可选）将他人分享的对应元数据文件 `<地图名>_meta.json` 也添加进`streamingAssets`目录下，即可自动还原该地图的地轴倾角
4. 运行工具，鼠标移动到画面左侧，引出侧边栏
5. 在侧边栏下方列表中，点击选中刚刚添加的地形图即可

**自行生成方式**

1. 得到他人生成地形图时使用的**随机种子**（如生成时没有填写，则生成后会将使用的随机种子显示在种子的输入栏）
2. 得到他人生成地形图时使用的**水面占比**
3. 得到他人生成地形图时使用的**地轴倾角**
4. 运行工具，鼠标移动到画面左侧，引出侧边栏
5. 将得到的随机种子填写进侧边栏顶部的种子输入框中
6. 将水面占比拖动至与他人相同的值
7. 将地轴倾角拖动至与他人相同的值
8. 点击生成按钮后等待结果即可
