新增：

- **星球大小可以设置**：生成时可指定 0.4× ~ 2.5× 地球半径（2548 ~ 15928 km），
  星球本体会按比例缩放，镜头距离同步等比跟随，换到更大/更小的星球上构图不变
- **自转方向可以设置**：可选顺向 / 逆向。逆向自转时太阳反向绕行（太阳自西向东升），
  时间滑块的流转方向随之改变
- 星球大小与自转方向都是**地图属性**，随地图一起保存，切换地图时自动应用；
  老地图没有这两个字段，按「地球大小 + 顺向自转」处理，行为不变
- **内存不足时禁止选择过高的生成分辨率**：滑条上限按本机物理内存自动收紧，
  连最低档都放不下时禁用生成按钮；脚本调用也会被同样的规则拦住

优化：

- **大幅降低生成峰值内存**：彩色图改用 32 位色（每像素 16 字节 → 4 字节）、
  大图在步骤之间强制 GC、显示贴图生成后释放 CPU 侧副本
  —— 8192 档实测从 3.57 GB 降到 1.66 GB，峰值从 4.3 GB 降到 1.8 GB
- **修复「每轮生成后内存涨约 300 MB」**：`Destroy` 只是打标记，
  现在换图时销毁旧贴图、并在生成结束后主动调用 `Resources.UnloadUnusedAssets()`
  与一次紧凑 GC，两轮实测内存已稳定（同阶段差异 1~5 MB）
- 分辨率的内存估算按实测重新标定，提示文字改为「内存 约 X｜本机最高 Y」

修复：

- 生成完成后不再保留整份中间结果（8192 档约 2 GB 的大数组）
- 切换地图时旧的高度图 / 板块图贴图不再泄漏

工程：

- 新增 `Assets/Editor/WindowsBuild.cs`：命令行 `-executeMethod` 可无头构建 Windows 播放器
- 新增 `scripts/release.ps1`：一条命令完成 提交 → 打标签 → 推送 → 构建 → 打包 → 上传 Release
- 新增 `.github/workflows/release.yml`：推送 `V*` 标签时在自托管 Windows runner 上自动出包
