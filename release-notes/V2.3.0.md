新增：

- **自然群系生成与着色**：地形图上的陆地现在按**生物群系**上色，而不是「海拔越高越棕」的
  单一渐变 —— 同一海拔的湿润区是森林、干旱区是沙漠，一眼就能分开。
  共 13 种群系：海岸、沼泽、雨林、温带林、针叶林、稀树草原、草原、干草原、沙漠、戈壁、
  苔原、高山草甸、裸岩
- **判定是气候优先的**：输入气温（海平面气温按纬度与地轴倾角推算，再按 5.5℃/km 递减到
  该海拔）、湿度（风带 + 大陆性 + 雨影）、海拔与坡度，按「海岸 → 沼泽 → 气温带 × 湿度带
  矩阵」判定。海拔不再直接命名地表，只通过气温递减与坡度起作用
- **地形起伏阴影**：陆地叠加方向光与坡度压暗，色块之下仍能看出山脊与谷地；
  另有两层颗粒噪声让大片同色群系有深浅变化

优化：

- 群系阈值按本工程气候场的实测分布标定（陆地湿度 p25=0.009 / p50=0.118 / p75=0.392），
  而不是照搬地球尺度。最初按地球直觉定档时沙漠占陆地 53%、森林只剩 2.5%，
  标定后沙漠约 26%、森林类约 30%
- 起伏阴影改用**陆地坡度的 95 分位**归一化。第一版用全图最大梯度，海岸线的落差把它顶爆，
  内陆起伏全被压成 0，渲染出来像一张平涂色块

修复：

- 陆地着色不再只依据海拔；旧分类器里按海拔命名的丘陵 / 高原 / 台地不再参与着色
  （枚举值保留，避免影响已保存数据）
