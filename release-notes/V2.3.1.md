修复：

- **孤立岛屿被判成整片荒漠**：群系判定原先直接使用参与侵蚀/水文的「降水型」湿度场。
  副热带下沉把该纬度带的降水压到 0.04，**但海洋本身照样在蒸发** ——
  结果副热带纬度上的岛屿与海岸也被判成荒漠（实测该纬度带海洋湿度中位数仅 0.040，
  陆地从海岸往内一步就掉到 0.02 以下）。
  现在群系改用独立的 `ComputeBiomeMoistureField`：海面取平缓的蒸发曲线，
  副热带干燥由「下沉系数」单独施加且**只压陆地**。
  连通块实测：中等岛 / 小岛的荒漠比例从「绝大部分」降到 **0%**，平均湿度 0.57~0.94；
  主大陆内部仍保留 21% 荒漠（大陆性 + 雨影，属应有行为）
- **大尺寸星球下阳光箭头穿模**：箭头与地轴的位置、尺寸原先写死在世界坐标里，
  星球放大到 2.5 倍时整根箭头会插进球体。现在按星球世界半径等比缩放位置与尺寸，
  地轴高度也跟着盖住球体

优化：

- 群系阈值按新的群系湿度场重新标定（p20=0.039 / p45=0.339 / p75=0.631）：
  `AridMax` 0.02→0.05、`SemiAridMax` 0.10→0.30、`SubHumidMax` 0.22→0.50，
  荒漠约占陆地 21%、草原类 28%、森林类 15%
