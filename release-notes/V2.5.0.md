输出与呈现解耦（A）：降低生成与导出阶段的常驻内存。

优化：

- **成品彩色数组移出生成管线**：`TerrainContext` / `WorldGenResult` 不再持有三张 `Color32[]`，
  渲染三步从管线移除（12 → 9 步）。8192 档不再有 3×128 MB 的常驻数组与随后的
  贴图拷贝、PNG 编码副本
- **流式导出**：新增 `MapExporter`，按 256 行条带渲染并 `SetPixels32` 直接写入贴图，
  编码后立即 `Apply(false, true)` 释放 CPU 侧像素。条带缓冲在 8192 档仅 8 MB
- **起伏阴影去掉整幅临时数组**：原实现为计算阴影分配整幅 `float[]`（8192 档 134 MB），
  改为逐像素即时求梯度，归一化尺度用抽样 p95
- **删除重复计算的群系湿度场**：它与 `Moisture` 输入完全相同，8192 档白算一整份 134 MB
- **导出开关**：高度图 / 板块图 / 人文三项可勾选，不再无条件写盘（地形图始终写，
  否则地图列表里加载不回来）

实测（离线验证台）：

- 4096 管线峰值：开步骤间 GC 420 → **396 MB**；关 GC 856 → **791 MB**
- `MapResolution` 估算：57 → **41 字节/格**
- 地形图输出与改前差平均 0.012 灰阶、最大 1（起伏归一化改为抽样，属允许的 ±1）
- **11 个地形 dump 与基线逐位一致** —— 只改输出路径，不碰生成语义
