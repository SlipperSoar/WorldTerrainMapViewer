数据类型瘦身（B）：继续降低生成期内存。

优化：

- **`TerrainType[]` → `byte[]`**：地形分类每格 4 → 1 字节
- **`plateIds int[]` → `ushort[]`**：板块归属每格 4 → 2 字节（板块数远小于 65535）
- 同步更新 `MapResolution` 估算：**41 → 32 字节/格**

实测：

| 指标 | 2.5.0 | 2.6.0 |
|---|---|---|
| 4096 生成峰值（步骤间 GC） | 396 MB | **321 MB** |
| 4096 生成峰值（Unity 内实测） | 728 MB | **677 MB** |
| 8192 生成峰值 | 1370 MB | **1080 MB** |
| 逐格占用 | 41 B | **32 B** |

一致性：

- **11 个地形 dump 与基线逐位一致**（纯存储瘦身，不改数值）
- 群系分布（陆地 110549 格）与地形图颜色指纹未变化
- stepcheck / resolutioncheck / biomecheck / planetcheck / orbitstate / seasoncheck 全部通过

说明：

- 距「8192 < 1 GB」还差约 80 MB，剩余空间在四个水文浮点数组（`riverWidth` / `discharge` /
  `waterDepth` / `catchmentMoisture`，各 4 B/格）。把它们改成 ushort 定标或按需生成即可跨过，
  但会牵动 HydrologyGenerator 的多趟写入与人文/渲染读取，留到下一轮
