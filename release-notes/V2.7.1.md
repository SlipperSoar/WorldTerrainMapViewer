修复导出贴图的行映射错误（2.5.0–2.7.0 的回归）。

修复：

- **地形图贴图/星球上每 256 行出现一道硬缝**：流式导出把每条带写到
  `贴图行 = 高度 - 带起始 - 带高`，而 `SetPixels32` 的块内行序是自下而上，
  于是每条带都被就地上下镜像 —— 2048 档 4 条带全部镜像，星球上看就是配色错乱、极冠跑到赤道附近
- 正确映射是 **图像行 y ↔ 贴图行 y（第 0 行 = 北极）**。这不是随意约定，而是被着色器钉死的：
  `EarthSurfaceLitShader` 里 `uv.y = 1 - (lat/π + 0.5)`，北极 → `uv.y = 0`，
  而 Unity 的 `uv.y = 0` 就是贴图第 0 行。写出的 PNG 是「南极朝上」，
  但 Unity 导入时会再翻一次，所以往返一致（与 2.4.0 及更早的行为相同）

验证：

- 用 `GenerationProbe` 在团结引擎内导出 1024×512：与验证台参考渲染
  **上下翻转后逐像素平均差 2.6**（残差来自 Mono 与 .NET 的浮点差异，改前也是同一量级），
  直接对比则是 47.4 —— 说明行映射已正确
- 目检：无 256 行接缝，极冠位于两极
- 11 个地形 dump 与基线逐位一致；全部验证台通过
