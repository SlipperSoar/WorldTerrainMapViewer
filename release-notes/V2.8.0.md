PNG 输出改为上北下南，不再依赖 EncodeToPNG 的行序。

新增/优化：

- **新增 `PngStreamWriter`**：按渲染顺序直接写 PNG 扫描线（zlib + IDAT），
  导出的 PNG 文件第一行就是北极，外部软件打开不再上下颠倒
- **省掉一张编码用贴图**：旧路径要为 EncodeToPNG 保留一张可读贴图（8192 档 128 MB），
  现在直接把条带写成扫描线。4096 探针实测 Unity 已分配 **230 MB → 134 MB**
- 贴图与 PNG 现在各走各的行序：贴图第 0 行 = 北极（着色器要求），PNG 第一行 = 北极（人看）

兼容性：

- `_meta.json` 新增 `pngNorthUp` 标记。新地图写 `true`，载入时自动翻转一次；
  **老地图没有该字段，行为完全不变**

验证：

- 1024×512 导出与验证台参考渲染直接比对平均差 **2.646**（残差为 Mono/.NET 浮点差异），
  翻转后比对 47.4 —— 确认文件已是上北下南
- 4096 探针：生成峰值 677 MB，导出 3.5 s，三张 PNG 正常落盘
- 11 个地形 dump 与基线逐位一致；全部验证台通过
