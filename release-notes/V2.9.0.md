地图存储改为「配方 + 按需导出」。

新增：

- **生成不再写 PNG**：生成完成后只写 `_meta.json`（几百字节的整型配方），
  地图列表靠它列出条目。想看地图不再需要写三张几十 MB 的图
- **独立的「导出当前地图」按钮**：点一次写出整套 —— 地形图 / 高度图 / 板块图 /
  人文 JSON / meta（`MapPublisher.ExportFull`）
- **按配方重建**：只有配方的地图被选中时，按 JSON 里的整型配方重新生成
  （`WorldTerrainGenerator.GenerateFromRecipe`），沿用原地图名
- **上次地图缓存**：同一份配方再次选中时直接复用上次的生成上下文，
  只重新渲染显示贴图（1~3 秒），不重跑管线（8192 档约 32 秒）

整型配方（`MapRecipe`）：

- 水面用千分比、倾角用毫度、半径用米，种子/宽度/版本都是整型
- UI 的浮点只在这一个入口被量化一次；之后所有浮点都由整型换算
  （`permille / 1000f`），因此 JSON 文本往返不会产生精度漂移，
  同一份配方必然展开成逐位相同的生成参数

兼容性：

- 老地图（有 PNG、没有配方字段）行为完全不变，仍直接载入 PNG
- 地图列表同时列出「有 PNG 的老地图」和「只有配方的新地图」

验证：

- 编译门 0 错误；stepcheck / resolutioncheck / biomecheck / orbitstate 全部通过
- 11 个地形 dump 与基线逐位一致
