迁移到 Unity 2022.3.62f3c1，并优化 PNG 写出与内存护栏。

平台迁移：

- 工程从团结引擎（Tuanjie 2022.3.62t11）迁到 **Unity 2022.3.62f3c1**
- 场景改为 `Assets/Scenes/MainScene.unity`（原 `.scene` 已删除），构建设置同步更新
- `ProjectSettings/` 与 `Packages/` 由新版编辑器重写
- 发布脚本、构建入口与文档里的引擎路径改为 `Unity.exe`

优化：

- **PNG 写出更快**：CRC-32 改为查表（原来每字节 8 次位循环）；adler32 按 5552 字节分块取模
  （不再逐字节 `% 65521`）；IDAT 直接写 `MemoryStream` 的缓冲，省掉 `ToArray()` 的整份拷贝
- **内存护栏统一**：`GenerateWorld` 与 `GenerateFromRecipe` 共用 `GuardMemory`，
  从列表里点选一张 8192 档配方图也同样受本机物理内存限制，绕不过去

修复：

- 生成完成回调改传**地图名**，不再传一个尚不存在的 PNG 路径
- 选中磁盘上的 PNG 快照时同步生成器的「当前地图」，避免点「导出」写出上一次生成的那张图
- 导出失败提示区分「尚无地图」与「当前是磁盘快照」

其它：

- 移除 Codely 插件相关文件（`.codelyignore` / `.com-unity-codely.json`）

验证：

- 编译门 0 错误；Unity 2022.3.62f3c1 编辑器内 `COMPILE_OK`、`error CS = 0`
- 11 个地形 dump 与基线逐位一致
- stepcheck / resolutioncheck / biomecheck / orbitstate 全部通过
- Unity 内探针全绿：只存配方、导出五件套、同一配方两次生成逐位一致；
  导出的 PNG 经外部库完整解码校验（CRC/adler 有效、上北下南、与参考渲染一致）
