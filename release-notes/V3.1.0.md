行星渲染改造步骤 1：数据契约。新增两张 RGBA8 数据贴图与元数据里的渲染参数，为后续的独立水面、法线贴图、大气与地形 LOD 提供数据基础。生成语义完全不变。

新增：数据图层（导出整包时随包落盘，生成仍只写 _meta.json）：

- `<名字>_surface.png`：R=高度（-10000~10000 m）、G=水体硬掩膜（0/255）、B=气温（-40~40 ℃）、A=湿度（0~1）
- `<名字>_detail.png`：R/G=切线空间法线 XY、B=AO、A=粗糙度
- 两张图与可见三图一样上北下南（第一行=北极），由 PngStreamWriter 流式写出、线性非 sRGB；只写文件不建 Texture2D
- 编码常量集中在 SurfaceContract，按行带渲染在 SurfaceDataLayers.cs；解码公式与外部采样工具见 VERIFICATION.md 第 19 节

新增：_meta.json 渲染参数（version 3，老地图缺字段按缺省值兜底，载入不受影响）：

- `seaLevelMeters`：海平面（恒 0，海平面标定后高度场以 0 为海平面）
- `snowLineEquatorMeters` / `snowLineMidMeters` / `snowLinePoleMeters`：赤道 / 45° / 85° 雪线（按地图起伏标定）
- `tideAmplitudeMeters` / `tidePeriodDays`：潮汐振幅与周期
- 全部由「高度场 + 地轴倾角」纯函数算出，同一配方两次生成必然一致

修复：
