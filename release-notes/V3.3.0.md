行星渲染改造步骤 2 的剩余增量：独立水面着色、法线贴图、AO / 粗糙度、潮汐。生成语义与数据契约完全不变（11 个 dump 指纹逐位一致）。

水面做到水平面高度：

- 此前开「地形凹凸」时，海洋会按高度场的负值被凹下去。现在**水体像素的顶点位移钳到海平面（0）**，水面水平；深度只用颜色区分，不靠几何
- 顶点阶段按静态水体掩膜判断，几何稳定；潮汐只影响颜色，不会让球面每帧抖动

独立水面着色（地表 shader 内按分类分支，不新增球壳）：

- 新增 `Assets/Shaders/SurfaceShading.cginc`，ForwardBase / ForwardAdd 两个 pass 共用
- 按 `_surface.png` 的 G 通道分类（河 / 湖 / 浅海 / 深海 / 海冰 / 冰川 / 雪峰）分别配色
- 深浅由 `_surface.R` 反推的水深做渐变；河/湖偏绿、三角洲带泥沙、冰走冷白
- 近岸与潮汐涨落带白色泡沫；水面高光更强更锐
- **潮汐动态海岸线**：涨潮把邻近低地染成水、退潮露出，只有颜色变化
- 无数据图（导入的单张 PNG）自动关掉水面着色，保持原样

法线贴图 / AO / 粗糙度（**只用于陆地**）：

- `_detail.png` 的 RG 重建切线空间法线，球面解析 TBN（含极点退化保护），扰动 `NdotL`/`NdotH`
- AO 乘进环境光，粗糙度控制高光锐度
- **水面不套法线**：`_detail` 的法线来自高度场梯度，海洋格是海底负值，贴到水平
  海面上会变成错误的波纹。水面保持球体法线（水平），深度只用颜色区分
- 无数据图时退回球体法线

潮汐：

- 复用 V3.2 已写入 `_meta.json` 的 `tideAmplitudeMeters` / `tidePeriodDays`
- `EarthManager.Update` 每帧把累计天数写入 `_TideTime`，shader 用 `sin` 算海平面升降
- 默认 30 秒一个「地球日」、半日潮约 15 秒一次涨落，参数在 EarthManager 上可调
